# 二人食记 📖

记录我们做过的每一顿饭。一餐一张照片，配日期、餐次、标签和备注，先按月、再按天分组（同一天的午晚饭归在一组），整理成一本「料理手帐」。

**添加、编辑、删除都在网页界面里完成，不用写任何代码。**

## 怎么用

### 1. 启动（二选一）

- 双击 **`启动二人食记.bat`**（推荐，最简单）
- 或在终端运行 `npm start`

启动后会自动打开浏览器访问 **http://localhost:5180**（端口被占用时会自动顺延）。
关掉那个黑色窗口 = 停止服务。

### 2. 在网页里操作

- **改标题 / 副标题**：**双击**页面顶部的「二人食记」或「把两个人吃过的每一顿饭…」，直接输入新文字，回车（或点其他地方）即保存；按 Esc 取消。
- **添加**：点「＋ 添加一餐」→ 选择照片文件上传（或从已有照片里选）→ 填标题 / 日期 / 餐次 / 标签 / 备注 → 保存
  - 上传照片后，**日期和餐次会自动按照片的时间建议填好**，一般只需补个标题
- **编辑**：鼠标移到卡片上，点卡片底部的「编辑」
- **删除**：点「删除」（会二次确认，照片文件不会删）

所有改动都会保存到 `data/data.js`（标题/副标题保存在 `data/site.js`），下次打开还在。

### 3. 只想看不想改

直接双击 `index.html` 也可以浏览（只读模式，不能添加、编辑、双击改标题）。要完整使用请按上面启动服务。

## 项目结构

```
menu/
├── server.js            # 本地服务（零依赖）：静态文件 + 增删改 API + 照片上传
├── 启动二人食记.bat      # 双击启动
├── index.html           # 网页（服务模式 / 只读模式都能用）
├── css/style.css        # 样式（温暖手帐风）
├── js/app.js            # 前端逻辑：分组 / 筛选 / 统计 / 增删改表单
├── data/data.js         # 餐食数据（服务自动维护，也可手动编辑）
├── data/site.js         # 站点设置：标题 / 副标题（双击标题后自动生成）
├── photos/              # 照片都在这里
├── scripts/
│   ├── lib.js           # 公共模块（数据读写 / 日期识别 / 校验）
│   └── add.js           # 命令行录入脚本（备用，日常用网页即可）
└── README.md
```

## 手动编辑数据（可选）

直接改 `data/data.js` 也行。每条记录：

```js
{
  "id": "2025-03-20-晚餐",          // 唯一，不能重复
  "date": "2025-03-20",             // YYYY-MM-DD
  "title": "晚餐：番茄牛腩 + 蒜蓉油麦菜",
  "photo": "photos/xxx.jpg",        // 相对 index.html 的路径
  "meal": "晚餐",                    // 早餐 | 午餐 | 晚餐 | 加餐
  "tags": ["家常菜"],
  "notes": "备注，可留空"
}
```

## 注意事项

- **支持图片格式**：jpg / jpeg / png / webp / gif。iPhone 的 HEIC 请先在手机设置里改为「兼容性最佳」再上传。
- **端口**：默认 5180，被占用会自动换下一个端口并在窗口里提示实际地址。
- **数据安全**：建议定期把整个文件夹备份一份（照片 + `data/data.js` 都在里面）。
- 想换首页标题、配色或加新功能，随时说一声。

## 命令行备用方案（不常用）

如果哪天想批量录入，也可以：把照片放进 `photos/`，运行 `npm run add`，按提示操作。
